AvilonX - ACR122U reader helper (Windows)

1. Unzip this folder (right-click > Extract All). Do not run it from inside the zip.
2. Plug in the ACR122U and double-click "Start ACR122U for AvilonX.cmd".
   The window shows this computer's Device serial.
3. The AvilonX Super Admin registers that serial on "Register RFID reader"
   for your club, Used by: Club admin (registering pigeons), and gives a device key.
4. Paste the device key into the window and press Enter (saved for next time).
5. Keep the window open. On Race entries, Bird bonding or Show up choose
   "Wireless", then tap tags on the ACR122U.

Other option: "Start ACR122U keyboard helper.cmd" types each tag into the window
in front (choose "Wired" and click the browser page after starting it).
